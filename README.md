# Python OOP Inheritance Assignment

โปรเจกต์นี้เป็นการทดลองและฝึกฝนการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming - OOP) ในภาษา Python โดยเน้นเรื่อง **การสืบทอดคุณสมบัติ (Inheritance)** ระหว่างคลาสแม่ (Parent Class) และคลาสลูก (Child Class) รวมถึงการจัดการโครงสร้างข้อมูลแบบต่างๆ

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (File Structure)

โปรเจกต์นี้ประกอบด้วยไฟล์ Python ทั้งหมด 3 ไฟล์หลัก ดังนี้:

### 1. `bag_set_queue.py`
ไฟล์ระบบจัดการคอลเลกชันข้อมูล Custom Data Structures โดยใช้หลักการ Inheritance
* **`Data` (คลาสแม่):** เป็นโครงสร้างพื้นฐานสำหรับเก็บและจัดการข้อมูลแบบ List โดยมีการแยกอิสระของข้อมูลด้วย `.copy()` ใน `__init__` เพื่อป้องกันปัญหา Shared Reference
* **`mySet` (คลาสลูก):** สืบทอดจาก `Data` โดยปรับแต่งการแสดงผล (`show`) ให้กรองข้อมูลที่ไม่ซ้ำกัน และลบข้อมูลที่ระบุทั้งหมดออกเมื่อสั่ง `delete`
* **`myBag` (คลาสลูก):** สืบทอดจาก `Data` โดยเน้นการเก็บข้อมูลซ้ำได้ และสั่งลบข้อมูลออกจากถุงทีละ 1 ตัวตามที่ระบุ
* **`myQueue` (คลาสลูก):** สืบทอดจาก `Data` โดยจัดการข้อมูลตามหลัก **FIFO (First In, First Out)** นำข้อมูลตัวหน้าสุด (index 0) ออกด้วย `.pop(0)`

---

### 2. `human_data.py`
ไฟล์จำลองโครงสร้างข้อมูลมนุษย์/บุคคล โดยใช้หลักการ Inheritance ในการสืบทอดคุณสมบัติและพฤติกรรม
* **Parent Class (คลาสแม่):** นิยามข้อมูลพื้นฐาน เช่น ชื่อ, อายุ, หรือข้อมูลทั่วไป
* **Child Class (คลาสลูก):** ปรับแต่งความสามารถพิเศษเฉพาะทาง (Method Overriding/Extension) สำหรับบุคคลแต่ละประเภท

---

### 3. `vehicle.py`
ไฟล์จำลองโครงสร้างข้อมูลยานพาหนะ โดยใช้หลักการ Inheritance
* **Parent Class (คลาสแม่):** เก็บคุณสมบัติร่วมของยานพาหนะ เช่น แบรนด์, รุ่น, ความเร็ว หรือระบบเชื้อเพลิง
* **Child Class (คลาสลูก):** ขยายความสามารถแยกตามประเภทยานพาหนะเฉพาะ เช่น รถยนต์, รถจักรยานยนต์ หรือรถไฟฟ้า

---

## 💡 แนวคิดหลักทาง OOP ที่นำมาใช้วิเคราะห์ (Key Concepts Used)

1. **Inheritance (การสืบทอด):** การให้คลาสลูกดึงคุณสมบัติ (`self.data` หรือ Attributes อื่นๆ) และเมธอดจากคลาสแม่มาใช้งานโดยไม่ต้องเขียนโค้ดซ้ำ
2. **Method Overriding:** การเขียนเมธอดในคลาสลูกทับเมธอดของคลาสแม่ เพื่อปรับเปลี่ยนพฤติกรรมให้เหมาะสมกับคลาสลูกนั้นๆ (เช่น การลบข้อมูลที่ต่างกันใน `Set`, `Bag`, `Queue`)
3. **Encapsulation & Data Isolation:** การแยกอิสระของข้อมูลใน Instance แต่ละตัว ไม่ให้ส่งผลกระทบต่อกันในหน่วยความจำ (RAM)
4. **State Mutation:** การออกแบบฟังก์ชันประเภท Mutator (เช่น `delete`) ให้เน้นการอัปเดตสถานะของวัตถุโดยตรงอย่างชัดเจน
